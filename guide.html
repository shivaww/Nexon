How to use Nexon

Nexon v1.0.24 · Android 7.0+ · Termux

What you need

  • An Android 7.0+ phone.
  • Termux from F-Droid — the Play Store build won't work.
  • Python 3.10+ inside Termux.
  • An API key from a supported provider — OpenAI, Google, Mistral, xAI, DeepSeek, Groq and more (36 built-in providers), plus Claude through the Anthropic API or OpenRouter.

Step 1 — Install the app

Download the latest APK from GitHub Releases and install it on your phone.

Step 2 — Set up the bridge

Nexon's agents run through a small Python bridge inside Termux. In Termux:

git clone https://github.com/shivaww/Nexon.git
cd Nexon && chmod +x install_bridge.sh && ./install_bridge.sh

The setup script installs the bridge's Python dependencies and prepares the workspace.

Step 3 — Start the bridge

cd ~/nexon_bridge && python3 mcp_server.py

The bridge serves a local WebSocket on port 8765 and HTTP on 8390. Keep it running while you use the app.

Step 4 — Add your API key

Open Nexon, go to Settings → API Keys, and paste a key from a provider you have an account with. Keys are stored on your device — in the app's secure storage — and only ever sent to the provider you picked. Pick a model in the model center; model lists are fetched live from the provider, so new releases appear without an app update.

Step 5 — Use it

  • Chat. Plain conversations with any connected provider.
  • Agentic work. Agents can run shell commands and edit files in Termux. Every tool call passes the permission guard first — ask, session, always, or never. You decide what runs.
  • Web search. Live search runs through Tavily; add a Tavily key to enable it. Sources stay attached to answers.
  • Deep research (beta). A three-phase pipeline — planner, researcher, synthesizer — that searches the web, extracts structured facts, and writes a cited report. In beta: results can occasionally be uneven.
  • Artifacts. Reports and code render in the feed and export as .md or .docx.

Optional

  • Google Drive backup. Sign in to bundle chats, settings, keys, and artifacts into one encrypted file in your own Drive. See the privacy policy for exactly what it contains.
  • Updates. The app checks GitHub (or Nexon's update server) and offers the APK when a new version ships.

Troubleshooting

  • Termux must come from F-Droid — Play Store builds are incompatible.
  • Bridge not connecting? Make sure python3 mcp_server.py is running and ports 8765/8390 aren't in use.
  • Anything else: open an issue or write to founder@nexonai.me.
