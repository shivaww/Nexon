$ man nexon

An agentic development and
research environment for Android.

Nexon brings agentic workflows to Android through Termux. A Flutter interface in front, a Python bridge behind it, and a real Linux userland underneath — an AI coding environment, agentic shell and file tools, live web search, and a multi-agent deep-research pipeline, in a workspace that lives on your phone instead of a rented cloud machine.

It's built for developers who want a real toolchain when a desktop isn't around, and for anyone who wants capable agents running on hardware they own, with their own API keys.

$ nexon research "state of on-device agents"

Three agents, one pipeline,
zero vector databases.

Deep research in Nexon runs as an autonomous three-phase loop. Evidence is extracted into structured FACT and FINDING records — plain, auditable JSON — instead of an embedding index, so the whole engine fits on a phone.

phase 1 — planner

Decompose

Turns the question into a research plan: sub-questions, search angles, and a context budget the later phases have to respect.

phase 2 — researcher

Collect

Runs live web searches, reads results, and writes precise evidence records — numbers, dates, claims with sources — into the store.

phase 3 — synthesizer

Report

Compiles the evidence into a cited report inside a configurable token budget, rendered as a Markdown artifact you can export.

One device, two processes,
a socket between them.

Nexon split-processes by design: Flutter owns the UI and state, a Python bridge owns the Termux userland. They speak JSON-RPC over a local WebSocket — everything stays on the phone.

$ ls features/

Everything a working agent needs,
nothing it doesn't.

real shell, real toolchain

Agents run commands inside the actual Termux shell — compile with GCC, run tests, push to git. No sandboxed toy terminal.

surgical file edits

Read, patch, and diff files by line range. Every edit snapshots first, so any change can be rolled back.

permission guard

Every tool call passes a permission gate you control — ask, session, always, or never — before anything executes.

live web search

Chat sessions route search natively to Tavily for real-time context, with sources kept alongside answers.

artifacts, rendered properly

Markdown, syntax-highlighted code, and interactive SVG diagrams render in the feed, and export to .md or .docx.

claude support, byok

Use Claude models through the Anthropic API or OpenRouter with your own key — prompt caching and extended thinking are implemented natively. Model lists are fetched live from each provider, so new releases work the day they ship. Every major provider is built in — OpenAI, Google, Mistral, xAI, DeepSeek, Groq and more — or add any OpenAI-compatible endpoint. Your keys stay on your device.

$ ./install_bridge.sh

Running in about
three minutes.

Everything installs from your phone. You need an Android 7.0+ device, Termux from F-Droid, and Python 3.10+ inside it.

step 01

Install the app

Grab the latest APK from GitHub Releases and install it. Termux comes from F-Droid — the Play Store build won't work.

github.com/shivaww/Nexon/releases
step 02

Set up the bridge

Clone the repo inside Termux and run the setup script. It installs the bridge's Python dependencies and prepares the workspace.

$ chmod +x install_bridge.sh && ./install_bridge.sh
step 03

Start the server

Launch the bridge — WebSocket on 8765, HTTP on 8390 — then open Nexon and point it at your keys. That's the whole stack.

$ cd ~/nexon_bridge && python3 mcp_server.py
