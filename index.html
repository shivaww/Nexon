What is Nexon

Mobile-First Agentic Development

Nexon is an AI-powered mobile development and research environment designed to bring agentic workflows to Android through Termux. It combines an interactive Flutter UI with a local Python bridge to orchestrate shell execution, file manipulation, live web search, and multi-agent deep research loops — directly on your phone.

Capabilities

Built for Real Development Workflows

Everything you need to build, research, and automate from your Android device.

Agentic IDE

LLM agents execute commands directly inside the Termux shell, supporting compilers, tests, and script runners with rich file manipulation and granular security permission controls.

Deep Research Engine

3-agent autonomous pipeline moving through Planner, Researcher, and Synthesizer phases with structured fact and finding storage for maximum response quality.

Live Web Search

Real-time web context via Tavily API integration. Search requests during chat sessions are routed natively for up-to-date information retrieval.

Artifact Rendering

Renders rich markdown documents, syntax-highlighted code, and interactive SVG diagrams in the chat feed. Export artifacts as .md or .docx files.

Cloud Backup & Sync

Unified Google Drive sync bundles conversation sessions, settings, and credentials into a single backup with smart non-destructive merging.

Termux Integration

Full access to the Termux runtime — bash shell, GCC, git, Python, and all standard Unix tools running natively on your Android device.

Mobile-First

Development Without the Desktop

Nexon brings a full agentic development and research environment to Android — no laptop required.

Your phone is the workstation

Instead of requiring a desktop for every AI development workflow, Nexon runs the entire agentic pipeline natively on Android through Termux. The Flutter UI handles visualization and state, while the Python bridge manages execution — all on your device.

  • Full Termux shell access with compilers, git, and Python
  • Local execution — no cloud dependency for core workflows
  • Deep research loops that run autonomously on-device
  • Google Drive sync keeps your work backed up and portable
